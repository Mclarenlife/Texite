The TeX resource bundle is a subset of the official Tectonic tlextras-2022.0r0
bundle, selected using TeX Live package dependencies and Texite's core-CJK policy.
The package list is recorded in manifest.json; inventory.json records each file
and checksum. Selected file contents retain their original copyright notices.
Texite modifies ctexopts.cfg (a user configuration file) to select the bundled
Fandol Chinese fonts by default. SHA256SUM is replaced with a new bundle identity
so format caches cannot be inherited from the full upstream distribution.
Other selected package and font contents are unchanged, under original licenses.
https://data1b.fullyjustified.net/tlextras-2022.0r0.tar
https://github.com/tectonic-typesetting/tectonic-texlive-bundles
https://www.tug.org/texlive/copying.html
Corresponding original package sources and documentation are available at:
https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2022/
https://ctan.org/

The application does not enable shell escape or download packages at runtime.
Tectonic uses a XeTeX-derived engine and BibTeX. It does not replace a LuaTeX
engine, biber, or external programs required by some specialized documents.
