Texite 0.5.0 modular offline typesetting runtime

The default installer contains only pdfTeX and BibTeX binaries, selected runtime
packages from the frozen TeX Live 2025 distribution, and Texite configuration.
XeTeX/xdvipdfmx and LuaHBTeX are separate optional downloads. Modules retain their
original copyrights and licenses. No third-party engine binary is modified.

Pinned upstream distribution and corresponding source/documentation archives:
https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2025/tlnet-final/
https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2025/
https://tug.org/svn/texlive/branches/branch2025/Build/source/
https://www.tug.org/texlive/LICENSE.TL
https://www.tug.org/texlive/copying.html

TeX-Live-packages.json lists exact package revisions, runtime archive URLs,
SHA-512 checksums, and corresponding source/documentation archive locations.
The standard TeX Live license allows redistribution of the individual packages
under their respective licenses (including GPL, LGPL, LPPL, and font licenses).
Engine sources and build instructions are available in the linked frozen
TeX Live source distribution. Engine binary package source is part of that
source distribution, not a per-platform .source.tar.xz archive.

Texite supplies a private texmf.cnf, pdftexconfig.tex, English hyphenation
configuration, and ctexopts.cfg. Its ctex-fontset-texite.def selects bundled
Arphic fonts for pdfTeX; XeTeX/LuaTeX use bundled Fandol. Explicit document
fontset choices take precedence. Selected upstream macro/font files are not
modified. OpenType font resources are split into a separately managed module.

The optional Tectonic compatibility pack contains unmodified Tectonic 0.17.0
(MIT license, with third-party components under their original licenses), plus
the previously tested subset of the tlextras-2022.0r0 bundle. It has its own
resource ZIP; its ctexopts.cfg selects Fandol and its bundle identity is rebuilt.
https://github.com/tectonic-typesetting/tectonic/tree/tectonic%400.17.0
https://github.com/tectonic-typesetting/tectonic/tree/tectonic%400.17.0/dist
https://data1b.fullyjustified.net/tlextras-2022.0r0.tar
https://github.com/tectonic-typesetting/tectonic-texlive-bundles
https://ftp.math.utah.edu/pub/tex/historic/systems/texlive/2022/

Compilation never invokes a package manager or downloads missing resources.

Texite also retains two small upstream font support files in apps/desktop/fonts:
ps2pk35.map (Thomas Esser, public domain) from texlive-scripts, and the unchanged
8r.enc TeX Base1 encoding vector from dvips. Their source locations and verified
archive checksums are in apps/desktop/fonts/README.md. Original author notices
are preserved. The dvips executable is not included. These resources allow
pdfTeX to embed the already installed Base35 Type 1 fonts.
