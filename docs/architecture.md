# Texite 架构

本文描述 0.11.0 的模块划分、数据流和实现边界。Web 与 Electron 共用 React 界面；桌面主进程提供磁盘项目、离线编译、WebDAV、更新检查和 AI 连接。

## 模块

| 目录 | 职责 |
| --- | --- |
| `apps/web` | React 入口 |
| `apps/desktop` | Electron 主进程、预加载桥接、项目目录、编译资源、同步与外部服务 |
| `packages/core` | 项目模型、路径校验、编译诊断、修改历史、同步指纹及 AI 修改约束 |
| `packages/platform` | IndexedDB、项目归档、备份、恢复和 ZIP 导入导出 |
| `packages/workbench` | 项目空间、多项目选项卡、编辑工作区及操作调度 |
| `packages/editor` | CodeMirror、Visual 解析与编辑、查找替换、插入工具和差异视图 |
| `packages/preview` | PDF 与图片预览、编译诊断、源码和 PDF 定位 |
| `packages/ui` | 设置、选择器、对话框和主题样式 |

## 编辑与项目状态

Project 保存文件、文件夹、主文件、引擎和 revision。文本资源保存源码，二进制资源使用 base64。路径、数量和大小在导入、保存及主进程接口处校验。

Code 和 Visual 共享同一份 LaTeX 源码。Visual 通过源码偏移替换编辑块，编辑期间保持块边界稳定；复杂宏和未知环境保留源码。CodeMirror 为各文件保存选区与撤销历史。视图切换保留编辑器与 PDF 实例，项目切换先刷新保存队列，再加载目标项目。

项目空间提供搜索、新建、文件夹关联、ZIP 导入、多选、重命名、最近删除和属性查看。重命名只改变显示名称；新建或迁移目录使用项目名并处理重名。多个项目可同时保持为顶部选项卡，关闭选项卡不删除项目。

## 持久化与恢复

浏览器恢复副本保存在 IndexedDB。支持 File System Access API 的浏览器可关联本地文件夹；浏览器 ZIP 项目保存在站点存储中。

桌面 ProjectLibrary 保存项目 ID 与本机目录的关联。应用管理项目默认位于 `userData/projects/<项目名>`，用户也可选择其他保存根目录。目录选择和绑定由主进程管理，渲染进程不能自行提交任意保存根路径。

保存操作串行执行。写入前检查磁盘基线，发生外部修改时拒绝覆盖；单个文件使用临时文件与重命名提交。目录级保存不是多文件事务。普通保存不删除原有文件。

普通修改历史按项目保存在 IndexedDB，相邻 1.5 秒内的同文件编辑合并，限制为最近 150 条及 4 MiB 快照。恢复前建立独立备份，再将恢复结果与备份放入同一个本地事务。项目备份保存整个项目，支持带备注的备份及恢复；写回磁盘时仍执行冲突检查。普通修改历史和项目备份属于当前设备，不随普通 ZIP 导出或 WebDAV 同步迁移。AI 对话使用独立数据文件，并随 WebDAV 项目同步；普通 ZIP 仍只导出文稿。

## 离线编译

默认资源来自冻结版 TeX Live 2025，提供 pdfLaTeX、BibTeX、常用宏包及中文字体。XeLaTeX、LuaLaTeX 和 Tectonic 作为独立扩展。资源构建、模块依赖与许可见 [离线引擎与宏包](offline-runtime.md) 和 [第三方资源说明](runtime-notices.txt)。

编译流程为：读取项目快照、校验相对路径、创建临时目录、选择已安装引擎、执行必要的 TeX 与 BibTeX 轮次、解析日志、返回 PDF 和对应 revision。临时文件和缓存位于可写的应用数据目录。缺少引擎或宏包时返回错误，不自动换用其他引擎或联网安装资源。

编译任务互斥，支持取消进程树及 180 秒超时。编辑可以继续进行，但编译结果仍对应原始快照；源码变更后显示预览过期。编译失败保留此前 PDF。诊断保留最终 TeX 轮次的警告及相关 BibTeX 问题，完整日志可单独展开。

## PDF 与源码定位

PDF.js 提供连续页面、文本选择、页码导航、缩放、适合宽度、显示暗色和导出。仅渲染可视区域附近页面，并限制单页画布像素。PDF 暗色不改变导出内容。

桌面编译产生 SyncTeX 数据后，主进程解析文件、行号与页面坐标，渲染进程结合当前选区执行双向定位。修改后的源码与旧编译结果可能不再对应，应先重新编译。项目内已有 PDF 和图片也可直接预览。

## WebDAV

桌面 WebDAV 手动同步完整项目快照，包含源码、图片和 AI 对话（含任务恢复记录），不包含本机路径、密码、API 密钥、CLI 会话令牌或普通编辑历史。带对话的快照使用 texite-webdav-2，读取兼容旧版 v1；旧客户端会拒绝 v2，避免丢弃对话后覆盖云端。远端文件使用项目名，快照中的稳定项目身份用于保持关联；旧 UUID 文件名可在服务支持条件时迁移。

同步前比较本地与远端状态：只有一端变化时同步，两端同时变化时创建独立冲突副本。写入使用强 ETag 条件请求；服务不支持时拒绝覆盖。下载替换前保存本地完整备份。更换服务或账号会清除本机关联，停止关联不删除远端文件。密码由系统密钥存储加密；加密不可用时仅在当前进程保留。

## AI 助手

浮动助手提供 Agent、Codex 只读对话及自定义 API 对话。Agent 通过本机 Codex app-server 调用 Texite 暴露的文稿工具，修改前校验文件、原文和选区范围；本地事务同时保存变更与恢复记录。撤回前检查文稿是否又被手动修改，避免覆盖后续工作。

自定义 API 连接由桌面主进程发起，网页版受服务端 CORS 限制。普通编辑和本地编译不需要 AI 服务。连接方式、上下文范围及已知兼容性见 [AI 项目助手](ai-assistant.md)。

桌面对话以独立 JSON 文件保存在 `userData/ai-history`，按项目身份索引，由可信 IPC 和文件队列串行读写。首次启动迁移旧 IndexedDB 记录。桌面以文件为读取来源，IndexedDB 保留事务恢复副本；先写恢复记录再提交文稿，保存失败不能导致无恢复记录的修改。迁移目录先复制并检查冲突，最后原子切换配置，原目录保留。空记录作为删除标记同步，避免旧缓存复活已删除对话。网页版仍使用 IndexedDB。

Markdown 渲染使用 react-markdown、GFM 和 KaTeX，不执行原始 HTML，不自动加载远程图片。AI 浮窗支持四边与四角缩放，限制在视口内。

## 进程边界与更新

Electron 开启 contextIsolation 和 renderer sandbox，关闭 Node integration。IPC 校验主 frame 与来源，静态资源限制在构建目录；默认拒绝外部导航、新窗口与权限请求。应用通过白名单打开项目页面和发布页面。

更新检查读取 GitHub 正式发布版本，下载匹配平台的安装包并校验 SHA-256，启动安装包前再次验证。安装包保存在 `userData/updates`，校验后保持原文件名，安装后不会自动删除；关于页显示路径。Windows 卸载配置明确保留 userData，macOS 替换应用也不修改 Application Support 中的记录。手动清除用户数据或第三方深度卸载不在保留保证之内。不会自动降级。macOS 的签名和下载隔离检查由系统执行。

## 当前限制

网页版没有 WASM 编译器。Visual 不覆盖任意 LaTeX 语义，最终排版以编译 PDF 为准。未提供完整 TeX Live、Biber、MakeIndex、任意外部命令或所有商业字体。文件写入不提供目录级事务，原生 TeX 引擎也不构成操作系统级隔离环境。

未提供实时多人协作、内置云端编译或产品级账户服务。macOS 安装包尚未完成 Developer ID 签名和公证。
