# 版本边界

## 0.1：可用基础工作台

交付共享 Web/Electron 界面、本地项目恢复、ZIP、核心源码编辑、章节/引用/搜索、本机编译接口与真实 PDF 阅读。Windows/macOS 复用主进程与界面；实际打包和操作系统验证必须分别执行。

## 下一阶段：完整论文工作流

- 编译器集成覆盖实际中文论文、Biber、跨文件资源与大型项目。
- 保留编译产物并接入 SyncTeX 双向定位。
- PDF 文本层、搜索和按视口渲染多页。
- 文件重命名、删除、外部文件监视与冲突合并。
- 恢复记录轮换、本地版本历史和磁盘保存队列。
- 可取消、防抖的自动编译。
- 文献解析升级、公式局部预览和索引 Worker。
- UI 设置与工作模式持久化、macOS 原生菜单及快捷键提示。

## 浏览器离线编译

单独评估 WASM 引擎、授权、宏包与字体资源规模。先公布支持矩阵，再接入 Worker 调度、缓存完整性校验与离线就绪状态。PWA 安装及离线资源缓存尚未实现。

## 暂不实现

账号、云同步、多人协作、联网 AI、插件市场、任意 LaTeX 的 WYSIWYG 转换。没有承诺这些功能的上线日期。
