# 版本范围

## 0.9.1 维护更新

清理未使用的代码引用，将未使用变量和参数检查加入 TypeScript 构建，更新架构与功能范围文档。功能和项目数据格式延续 0.9.0。

## 已实现

- 项目空间、文件夹关联、ZIP 导入导出、层级文件树、多项目选项卡、项目重命名、最近删除与恢复。
- 源码和 Visual 编辑、中文查找替换、常用 LaTeX 补全，以及表格、图片、公式、符号和引用插入。
- 默认 pdfLaTeX 离线编译、BibTeX、编译诊断、取消与超时；可选引擎和宏包导入、卸载与恢复。
- 连续 PDF 预览、文本选择与词数统计、双向源码定位、PDF 与图片资源预览。
- 文件修改历史、差异预览、恢复前备份、带备注的完整项目备份与恢复。
- 桌面 WebDAV 手动同步、冲突副本、项目名快照和本地目录迁移。
- 浮动 AI 助手、Agent 文稿编辑、只读对话、自定义 API、修改差异及任务撤回。
- 外观、主题、字体和界面字号设置，记录清理，GitHub 正式版更新检查。

## 后续候选

以下项目尚未承诺发布时间，不属于当前版本功能。

- 更完整的 Visual 合并单元格、自定义环境和复杂宏编辑。
- 文件重命名与删除的完整交互、磁盘监听及交互式冲突合并。
- 更多中文论文模板、Biber 工作流和自动编译。
- 大型项目索引 Worker、PDF 全文搜索。
- 浏览器 WASM 编译、PWA 与资源离线缓存。
- macOS Developer ID 签名、公证及原生菜单。

当前不提供产品级账户、实时多人协作、云端编译或插件市场。
