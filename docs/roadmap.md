# 版本范围

## 0.2 已实现

项目空间、持久磁盘目录关联、ZIP 托管导入、层级文件夹、Code / Visual 编辑、顶栏编译与三种布局、PDF 页码 / 缩放 / 独立暗色、内置离线 Tectonic 和 TeX 资源。移除界面标语及导入 PDF 按钮。0.2.1 将内置资源裁剪为常用包与中文字体，并补齐本地 PDF 字符映射资源。
