# 版本范围

## 0.2 已实现

项目空间、持久磁盘目录关联、ZIP 托管导入、层级文件夹、Code / Visual 编辑、顶栏编译与三种布局、PDF 页码 / 缩放 / 独立暗色、内置离线 Tectonic 和 TeX 资源。移除界面标语及导入 PDF 按钮。0.2.1 将内置资源裁剪为常用包与中文字体，并补齐本地 PDF 字符映射资源。

## 0.3 已实现

连续 PDF 页面及滚动页码定位、Visual 嵌套格式 / 列表 / 常用表格 / 本地图片 / 多行公式 / input 文件预览；独立外观、主题配色、文字对比及字体设置；侧栏调宽和按行显示增删的本地修改历史。

## 后续

- SyncTeX 双向定位和 PDF 文本层、搜索。
- 更完整的 Visual 合并单元格、自定义环境和复杂宏编辑。
- 文件重命名 / 删除、磁盘监听、冲突合并与历史回退。
- 更丰富的中文论文模板、Biber 工作流支持。
- 自动编译与大型项目索引 Worker。
- 浏览器 WASM 编译、PWA 与资源离线缓存。
- macOS 签名公证、原生菜单和正式发布流程。

不包含账号、云同步、多人协作、联网 AI 或插件市场。
