# Texite

本地 LaTeX 编辑器，使用 React、TypeScript、CodeMirror 6、Motion、KaTeX、PDF.js 与 Electron，提供网页版和 Windows / macOS 桌面版。

当前版本：**0.9.0**，支持按项目名保存的本地目录与 WebDAV 快照、多项目选项卡、双向 PDF 定位、项目备份和记录清理。浮动 AI 助手包含 Agent／对话模式、行内编辑、可调整大小的差异窗口及自定义对话 API。支持桌面 WebDAV 手动同步，不包含云端编译；可选 AI 推理需要联网。

## 使用与开发

需要 Node.js 24+、pnpm 11。构建桌面编译环境另需 Python 3.11+ 和 curl。

```sh
pnpm install
pnpm dev                 # 浏览器 http://127.0.0.1:5173
pnpm runtime:prepare     # 构建时下载、校验并组装离线编译资源
pnpm exec install-electron
pnpm dev:desktop
```

`runtime:prepare` 在构建机器下载并校验冻结版 TeX Live 2025 的运行包，按模块组装默认 pdfLaTeX 环境与独立 XeLaTeX / LuaLaTeX 扩展。只取运行文件，不打包文档、源码或不需要的引擎。桌面安装包仅包含 `default.texite-runtime.zip`，预算上限 200 MB；安装后首次使用在本地展开模块和生成格式，无需 TeX、Perl 或联网下载。Tectonic 兼容扩展另用 `python scripts/prepare-runtime.py` 和 `python scripts/pack-tectonic.py` 构建，不进入默认安装包。

## 本版功能

- WebDAV（桌面版）：设置 → 同步与存储，配置服务地址、账号和应用密码。项目空间顶部“同步”拉取云端项目；选中一个或多个项目后，“上传项目”将它们关联到云端。侧栏底部循环图标双向同步本地云项目并拉取新项目，未配置时打开设置。重复拉取更新已有项目，最近删除中的项目不会自动恢复。云端关联项目显示云图标。同步采用完整项目快照（`.texite.json`），包含源码和图片，不上传本机路径、密码、编辑历史或 AI 对话。密码使用系统密钥存储加密。
- 同步冲突：仅一端修改时双向同步；双方都有修改时下载独立的云端冲突副本，保留双方原件。云端写入使用强 ETag 条件请求，服务不支持时拒绝覆盖。下载覆盖前的本地快照保存在 `userData/sync-backups`。更换服务或账号会清除本机关联；停止关联不会删除云端项目。支持 Basic / 应用密码认证，推荐 HTTPS；具体服务仍需验证读写权限和兼容性。
- 项目保存目录：设置 → 同步与存储，可更改后续新建、ZIP 导入和云端下载的保存路径。新目录使用项目名，重名追加 `(2)`、`(3)`，不再使用随机编号。“迁移当前项目”复制项目到以项目名命名的目录并切换保存位置，原目录保留为备份；旧编号目录也可通过此操作迁移。已有项目不会因修改默认路径而自动移动，项目显示名称的修改也不会移动关联文件夹。
- 项目选项卡：顶部同时打开多个项目，切换前保存编辑，关闭选项卡不删除项目。Windows 窗口按钮融入顶栏，左上 Logo 打开项目空间，视图按钮仅显示图标，悬浮查看名称。

- AI 助手（桌面版，实验性）：连接本机 Codex，选择模型、直接编辑或只读问答；读取当前缓冲区、修改多文件、运行内置编译，查看差异并撤回整次修改。使用说明见 [AI 项目助手](docs/ai-assistant.md)。

- 项目空间：点击左上角 LOGO，查看所有项目、搜索、新建、打开文件夹或导入 ZIP；支持多选、重命名、查看属性和删除。重命名只改显示名称，不修改系统文件夹名称。删除移到“最近删除”，可批量恢复，原文件与历史保留。
- 资源预览：点击项目中的 PDF 或常见图片（PNG、JPEG、GIF、WebP、AVIF、BMP、SVG、ICO），在编辑区直接预览；Ctrl/Cmd + 滚轮缩放。PDF 全部页面连续显示。
- 预览功能区：顶部 PDF／编译诊断页签切换整个预览区域；诊断区分错误、警告和可展开的排版提示，中文解释悬浮显示；支持定位报错行、复制信息和查看完整日志，切回 PDF 保留上次编译结果。
- 浮动 AI：默认窗口加大，标题栏可拖动，右下角可拖拽缩放；紧凑工具栏、按需展开连接详情、一体式输入框随内容增高，正文和输入文字默认 14px，可随界面字号调整。联网和上下文说明收进标题旁的问号提示。
- 文件夹项目：直接关联用户选择的系统目录，自动保存到原处；关联跨项目切换和重启保留。
- ZIP 项目：解压至应用管理的项目目录，支持资源文件、空文件夹和单层压缩包外包装目录。
- 项目文件：层级文件树，创建文件夹、子文件夹和文件，导入图片等资源。
- Code / Visual：共享同一份源码；Code 提供高亮、补全、查找替换和独立撤销历史；Visual 展示标题、嵌套文字样式、列表、常用表格、本地图片、多行公式及项目内 input/include，点击内容编辑对应 LaTeX。导言区和复杂命令保留源码，不做有损 HTML 转换。
- 编辑工具：中文查找替换、匹配计数和正则表达式；右键插入表格、图片、公式、符号、href、cite、ref。表格与图片支持跨双栏、居中、标题和标签，图片可按名称筛选；公式支持独立、行内、多行对齐、分段、矩阵及编号；符号面板支持分类与搜索。
- 顶栏：编译 / 取消编译，选择仅编辑器、仅 PDF 或拆分视图。
- PDF：全部页面连续排列，页码输入与前后按钮滚动定位，滚动同步当前页；总页数、缩放、适合宽度、独立暗色模式、导出 PDF。只渲染可视区域附近页面，限制单页画布像素。暗色只影响显示，导出的 PDF 不变。
- 编译：默认真正的 pdfLaTeX，支持中文、数学、表格、TikZ / PGFPlots、Beamer、BibTeX。选择哪个引擎就使用哪个；未安装时明确报错，绝不自动替换。底部状态栏显示引擎，悬浮可查看上次实际编译器；PDF 顶栏只保留 PDF／编译诊断页签。诊断更新为最后一遍仍存在的 LaTeX 警告，保留 BibTeX 问题；完整编译过程可展开原始日志查看。
- 引擎与宏包管理：设置 → 编译设置，查看占用、搜索宏包、预览并选择离线扩展模块，自动补齐包内依赖。卸载先确认并检查依赖，不更改文稿。可从随软件保留的默认资源恢复 pdfLaTeX 与常用宏包；可选引擎可从 [通用扩展包](https://github.com/Mclarenlife/Texite/releases/tag/v0.7.0) 下载对应平台的扩展 ZIP 后导入。新版本安装包继续兼容这些扩展，无需随每个软件版本重复下载。
- 设置：外观、文字、编译分区；浅色 / 深色 / 跟随系统使用工作台缩略图，六种主题使用配色卡片。文字对比度与字体也提供预览。界面字号可选大、中、小，独立于编辑器字号并自动保存。
- 文字颜色：正文、命令与关键字、参数与字符串、注释、括号与符号可独立调整；内置色板、饱和度 / 明度面板、色相滑条和 HEX 输入，无系统原生取色弹窗。右侧实时预览，设置自动保存，可按项恢复跟随主题。
- 侧栏：拖动边框调宽，也可聚焦分隔条按左右键；宽度跨重启保留。
- 修改历史：侧栏显示修改时间、文件与行号，点击后在编辑区显示原 / 新行号、绿色新增和红色删除，返回编辑不会回退文稿。选择“恢复到修改前”，先对比当前内容与目标版本，再确认恢复这个文件；系统自动创建独立恢复备份，可以再次预览并恢复到备份版本。
- 大纲、项目搜索、引用补全与命令面板。

Visual 是源码驱动的可视化编辑，自定义宏、合并单元格、复杂图形及特殊环境仍保留源码显示；它不是任意 LaTeX 的完整 WYSIWYG 排版器。最终版式以编译 PDF 为准。

## 保存位置

桌面应用管理目录为 Electron 的 `userData/projects/<项目名>`，同名项目自动加序号。默认位于 Windows `%APPDATA%/texite/projects` 或 macOS `~/Library/Application Support/texite/projects`，也可在设置 → 同步与存储中更改新项目的保存位置。具体位置显示在项目卡片中。更新、重装程序不会把项目放进只读安装目录。打开文件夹时始终写回所选原目录。

WebDAV 使用 `Texite/<项目名>.texite.json` 保存完整快照；上传时对同名项目加序号，非法路径字符替换为下划线。旧版编码文件会在同步时迁移为项目名，通过稳定项目身份保持新版设备之间的关联。重命名依赖服务的 MOVE、强 ETag 和条件写入支持；不支持时明确报错并保留原文件。建议同步设备一并升级至 0.9.0。

设置 → 同步与存储可分别清理本机所有项目的备份、修改历史、AI 记录，每项均需二次确认。AI 助手的垃圾桶按钮只清理当前项目、当前模式的记录；对话模式包含 Codex 与自定义 API。清理 Agent 记录也移除任务撤回记录，但保留已应用的文稿修改。项目源码与云端项目不会被清理。

设置 → 关于可检查 GitHub 最新正式版、下载匹配当前平台的安装包，并在 SHA-256 校验后打开安装包；不会自动降级。Mac 仍需将应用拖入应用程序目录，此流程不会绕过系统签名或下载隔离检查。

浏览器项目保存在 IndexedDB；Chrome / Edge 支持通过 File System Access API 关联本地文件夹。其他浏览器可使用 ZIP。浏览器安全限制不允许网页写入桌面软件的数据目录，因此 Web ZIP 项目保存在浏览器本地存储。

源码修改会防抖保存恢复副本；桌面版和已关联文件夹的网页版还会写回磁盘。`Ctrl/Cmd+S` 立即保存。检测到外部改动会拒绝覆盖，当前恢复副本保留在本地，可先导出 ZIP，再重新打开磁盘版本。文件写入按队列执行，桌面端逐文件原子替换；不提供目录级事务。普通保存不删除文件；撤回 AI 任务时，仅删除该任务新建且内容未再改变的文本文件。WebDAV 下载可同步删除文件，删除前验证磁盘内容并保存完整项目备份。

限制：500 个文件、500 个文件夹、约 50 MB 项目；不跟随桌面文件系统符号链接。清理浏览器站点数据会删除浏览器项目。

历史保存在当前设备的 IndexedDB，按项目隔离；相邻 1.5 秒内同文件的连续编辑合并，保留最近 150 条、最多 4 MiB 的源码快照。超容量修改会提示；不记录外部程序改动，也不随 ZIP 导出。恢复只替换对应的已有文本文件，其他文件保持不变。恢复前备份使用独立存储，不参与普通历史的 150 条 / 4 MiB 清理；备份和恢复后的项目在一个本地事务中提交，空间不足或写入失败则不恢复。磁盘同步仍检查外部修改冲突，失败时保留本地恢复结果与备份。清理应用或站点数据会删除历史及备份。

## 编译范围

桌面默认直接调用 **pdfTeX 1.40.28（TeX Live 2025 final）**，配合随软件提供的宏包、字体与 BibTeX，不依赖系统发行版或 latexmk，不下载资源。首次编译本地生成 pdflatex 格式，按需要运行多遍以解析目录、引用和参考文献；支持日志、取消、180 秒编译超时，失败保留上次 PDF。

pdfLaTeX 中文使用 CJK / CTeX 与 Arphic 字体，默认提供宋体、楷体（`\songti`、`\kaishu`）；不会把 Fandol OpenType 字体冒充为 pdfTeX 字体。需要黑体、仿宋或 `fontspec` / `unicode-math` 的文稿可自行选择并导入 XeLaTeX 或 LuaLaTeX（包含 Fandol），软件不会替用户改引擎。文稿显式指定的字体配置优先；指定未提供的字体会报错。

独立扩展：XeLaTeX、LuaLaTeX 使用同一冻结版 TeX Live 2025；Tectonic 0.17.0 使用旧版 TeX 2022 资源以便继续编译旧项目。已有项目保留原引擎设置，升级后若该引擎未安装，会提示导入。所有扩展来自 Release，导入时检查平台、清单、依赖与逐文件 SHA-256。扩展可能包含可执行文件，应使用可信来源。缺包不会自动联网补齐。Biber、MakeIndex、外部 shell 命令及未提供的特殊字体尚未打包。

要与 Overleaf 对齐，还需要相同的 TeX Live、模板、宏包与字体版本；使用同名引擎不保证不同发行版间排版完全相同。支持范围和模块格式见 [离线编译环境](docs/offline-runtime.md)。

**网页版目前不含 WASM 编译器。** 编译按钮会说明需要桌面版，不会上传文档或生成假结果。初始 PDF 是随仓库提供的预编译示例。支持 PDF 文本选择和词数统计；桌面编译支持源码与 PDF 双向定位。

## 验证和打包

```sh
pnpm test
pnpm build
pnpm exec playwright install chromium
pnpm test:e2e
node scripts/desktop-smoke.cjs
pnpm package
pnpm dist:win
pnpm dist:mac
```

打包命令会校验默认资源 SHA-256、必需模块、完整依赖、仅含 pdfLaTeX 引擎以及 200 MB 资源 ZIP 上限。Windows/macOS 应分别在对应平台构建，输出位于 `release/`。系统 Edge 可通过 `TEXITE_BROWSER_PATH` 指定，用于浏览器测试。

内置编译集成测试实际编译中文、图表、幻灯片、字体与参考文献，并读取 PDF 检查文字、页数与 pdfTeX Producer；另测四种引擎、卸载与导入、缺失依赖、损坏包、路径校验、编译错误及取消。本机没有准备 runtime 时明确跳过，桌面打包 CI 则先准备 runtime 再测试。可用 `TEXITE_TEST_RUNTIME` 指向打包产物中的 runtime 目录重复检查。基础 CI 另测系统 latexmk。桌面回归测试涵盖实际 IPC、磁盘保存、ZIP 目录、PDF 翻页、外部冲突和重启关联。

默认不包含代码签名或 macOS 公证。Windows/macOS 打包工作流可在 GitHub Actions 手动触发。

架构见 [docs/architecture.md](docs/architecture.md)，后续范围见 [docs/roadmap.md](docs/roadmap.md)，编译资源来源与许可见 [docs/runtime-notices.txt](docs/runtime-notices.txt)。应用源码尚未选择开源许可证；第三方组件仍遵循其各自许可证。
